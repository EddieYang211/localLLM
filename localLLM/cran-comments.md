# CRAN Submission Comments — localLLM 1.4.0

## Update

This is an update of localLLM 1.3.0, which is currently on CRAN.

Changes are documented in NEWS.md. Main points:

- The llama.cpp backend was upgraded from b8766 to b11869. This adds 38 new model
  architectures and makes parallel generation about 35% faster.
- Chat-template special tokens in prompts are now tokenized correctly. This was a
  community contribution (GitHub #6, #7).
- `generate_parallel()` no longer fails on recurrent and hybrid models.
- The macOS backend binaries now target macOS 13.3 and have CPU weight repacking
  enabled.
- `model_metadata()` is now exported. `model_load()` expands `~` in paths.
  `repeat_last_n`, `use_mmap` and `use_mlock` are validated.
- NAMESPACE is now generated by roxygen2. Its directives are unchanged.

## Runtime binary download

The package downloads a platform-specific compiled backend binary via
`install_localLLM()`. This download is user-initiated, explicit, and documented in
the README and vignettes. The binary is too large and too platform-specific to bundle
in the source package; the same approach is used by packages such as 'torch' and
'llama'.

The download URL points to a fixed, versioned GitHub Release of the package repository
(https://github.com/EddieYang211/localLLM/releases/tag/v1.4.0). No network access
occurs at package load time. The library is loaded from a local path only after the
user has run `install_localLLM()`. Examples, tests and vignettes do not download models
or the backend on CRAN.

- GitHub Actions: macOS (latest) R release; Windows (latest) R release;
  Ubuntu (latest) R release, R devel and R oldrel-1

  CI. An end-to-end smoke test (load a small model, tokenize, generate) passed on each.
